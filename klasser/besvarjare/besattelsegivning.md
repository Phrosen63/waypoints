# Besättelsegivning

När infernalikern blir besatt påverkas karaktärens kropp, resultatet varierar beroende på vilken demonisk entitet som besitter infernalikern.

Om infernalikern har en pakt med en demon, kan denna alltid användas för att besitta infernalikern. Om infernalikern saknar pakt måste hen först tillkalla en demon.

---

# Modifieringar

När en infernaliker blir besatt av en demon påverkas både styrkor och svagheter av demonens inneboende egenskaper. Varje typ av demon ger sin värd en unik uppsättning krafter, men också specifika sårbarheter.

Till exempel:

* Elddemoner förstärker värdens eldmagi och ger resistens mot hetta, men gör dem extra sårbara för vatten och is
* Icke-fysiska demoner låter värden passera genom fasta föremål och ger immunitet mot fysiska attacker, men är i gengäld mer känsliga för magiska angrepp
* Giftdemoner ger kontroll över toxiner och sjukdomar, samt immunitet mot gifter
* Drömdemoner låter värden manipulera andras sinnen och drömmar, men kan göra det svårare att skilja på illusion och verklighet
* Styrkedemoner förstärker värdens fysiska kapacitet mångfalt, men kan göra dem klumpigare och mindre rörliga

Samspelet mellan demon och värd skapar därmed en unik kombination av krafter som kräver att infernalikern lär sig utnyttja fördelarna samtidigt som hen kompenserar för svagheterna.

Vissa, starkare, demoner kan dessutom ge infernalikern tillgång till särskilda magiska förmågor och besvärjelser.

## Lägre demon

Lägre demoner saknar ofta magiska förmågor och kan därför inte stärka infernalikern i någon vidare utsträckning. Infernalikern påverkas alltid av demonens svagheter, exempelvis tar infernalikern mer skada från heliga attacker.

Kan fördrivas från infernalikern via besvärjelsen *Fördriva lägre demon*.

Spelaren slår 1T6, resultatet avgör modifieringarna som infernalikern drabbas av medan hen är besatt:

| Resultat | Modifierare |
| :--- | :--- |
| **1** | +3 STY, +3 fysisk skada<br>-6 magisk skada, -3 undvika attack |
| **2** | +10 fysisk skada<br>-10 total kroppspoäng |
| **3** | +6 Demonisk skada (demonologi)<br>-1 defensiv handling |
| **4** | +1 offensiv handling, +1 defensiv handling<br>-3 STY, -3 SMI, -3 FYS |
| **5** | +10 magisk skada<br>-10 fysisk skada |
| **6** | +5 fysisk skada, +5 magisk skada<br>All skada som drabbar infernalikern ökar med 5 |

## Medelstark demon

Medelstarka demoner har ibland någon enstaka magisk förmåga som kan stärka infernalikern. Infernalikern påverkas alltid av demonens svagheter, exempelvis tar infernalikern mer skada från heliga attacker.

Kan fördrivas från infernalikern via besvärjelsen *Fördriva lägre demon*.

Spelaren slår 2T6, resultatet avgör modifieringarna som infernalikern drabbas av medan hen är besatt:

| Resultat | Modifierare |
| :--- | :--- |
| **1** | +3 STY, +3 fysisk skada<br>-3 magisk skada, -1 undvika attack |
| **2** | +10 fysisk skada<br>-5 total kroppspoäng |
| **3** | +12 Demonisk skada (demonologi)<br>-1 defensiv handling |
| **4** | +1 offensiv handling, +1 defensiv handling<br>-1 STY, -1 SMI, -1 FYS |
| **5** | +10 magisk skada<br>-5 fysisk skada |
| **6** | +5 fysisk skada, +5 magisk skada<br>All skada som drabbar infernalikern ökar med 2 |

## Stark demon

Starka demoner har ofta några magiska förmågor som stärker infernalikern. Infernalikern påverkas alltid av demonens svagheter, exempelvis tar infernalikern mer skada från heliga attacker, men det är inte säkert att starka demoner har sådana svagheter.

Kan fördrivas från infernalikern via besvärjelsen *Fördriva högre demon*.

Spelaren slår 3T6, resultatet avgör modifieringarna som infernalikern drabbas av medan hen är besatt:

| Resultat | Modifierare |
| :--- | :--- |
| **1** | +4 STY, +4 fysisk skada |
| **2** | +10 fysisk skada |
| **3** | +12 Demonisk skada (demonologi) |
| **4** | +1 offensiv handling, +1 defensiv handling |
| **5** | +10 magisk skada |
| **6** | +5 fysisk skada, +5 magisk skada |

## Mycket stark demon

Mycket starka demoner har flera magiska förmågor som stärker infernalikern. Det är ovanligt för dessa demoner att ha svagheter som infernalikern skulle påverkas av.

Kan fördrivas från infernalikern via besvärjelsen *Fördriva högre demon*.

Spelaren väljer 3 modifierare som infernalikern drabbas av medan hen är besatt, samma modifierare kan väljas flera gånger:

| Resultat | Modifierare |
| :--- | :--- |
| **1** | +5 STY, +5 fysisk skada |
| **2** | +12 fysisk skada |
| **3** | +15 Demonisk skada (demonologi) |
| **4** | +1 offensiv handling, +1 defensiv handling, +3 attack, +3 undvika attack |
| **5** | +12 magisk skada |
| **6** | +7 fysisk skada, +7 magisk skada |

## Demonfurste

Demonfurstar är ohyggliga varelser som härskar i sina egna helveten, de har ofta arméer av lägre stående demoner under sig och förstärks av en stor mängd magiska förmågor. Demonfurstar har inga svagheter som infernalikern påverkas av.

Spelaren väljer 4 modifierare som infernalikern drabbas av medan hen är besatt, samma modifierare kan väljas flera gånger:

| # | Modifierare |
| :--- | :--- |
| **1** | +10 STY, +10 fysisk skada |
| **2** | +12 fysisk skada, +5% chans att utdela kritisk skada |
| **3** | +15 Demonisk skada (demonologi)<br>Infernalikern helas för 5 kroppspoäng varje gång någon annan tar demonisk skada |
| **4** | +2 offensiv handling, +2 defensiv handling, +5 attack, +5 undvika attack |
| **5** | +12 magisk skada<br>Infernalikern skyddas av en magisk rustning med 10 RV (staplar ej), som förnyas varje stridsrunda |
| **6** | +10 fysisk skada, +10 magisk skada, +2 i alla grundegenskaper |
