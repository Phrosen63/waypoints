# Ett rostigt gammalt svärd: Equilibrium

**Equilibrium** är ett förtrollat svärd som inte bara förändrar sina krafter utan även sitt utseende efter spelarens önskan. Till synes ett vanligt långsvärd, kan det på kommando flamma upp i eld, frysa till en iskall klinga eller svepa genom luften med kraften av en stormvind. Varje transformation påverkar inte bara svärdets utseende, utan även dess vikt, balans och ljud, vilket gör varje attack unik.

**Skada**: 2T10+10

**Special**: spelaren kan när som helst byta elementar för svärdet - det kan till exempel ske mellan två attacker. <br>Svärdet fungerar som en magisk katalysator och tillåter spelaren att kasta ännu en besvärjelse per SR, så länge det är draget.
