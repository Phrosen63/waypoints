# Skuggpesten

Denna sjukdom sprider sig snabbt genom kroppen och orsakar mörka fläckar på huden som verkar sprida sig som levande skuggor. Symptomen inkluderar svår utmattning, hallucinationer och en gradvis förlust av synen. Om sjukdomen inte behandlas kan den leda till permanent blindhet och svår svaghet.

## Symptom

En spelare som har drabbats av skuggpesten blir snabbt gradvis sjukare. Spelaren blir svagare, upplever hallucinationer och får sämre syn.

| Tid | Effekt |
| --- | --- |
| Första dygnet | -1 STY, <br>-1 PER, <br>-1 i sikta |
| Andra dygnet | -1 STY, <br>-2 skada på alla STY-baserade attacker*, <br>-1 PER, <br>-2 i sikta |
| Tredje dygnet | -2 STY, <br>-4 skada på alla STY-baserade attacker*, <br>-2 PER, <br>-2 i sikta |
| Fjärde dygnet | -2 STY, <br>-4 skada på alla STY-baserade attacker*, <br>-3 PER, <br>-5 i sikta |
| Femte dygnet | -4 STY, <br>-8 skada på alla STY-baserade attacker*, <br>-4 PER, <br>-5 i sikta |
| Sjätte dygnet | -8 STY, <br>-16 skada på alla STY-baserade attacker*, <br>-5 PER, <br>-10 i sikta |
| Sjunde dygnet | -12 STY, <br>-24 skada på alla STY-baserade attacker*, <br>-8 PER, <br>-Spelaren blir blind |

\*STY-baserade attacker: exempelvis slag, sparkar, hugg med vapen, skott med båge, etc.

## Kurering

Skuggpesten kan botas på två sätt: vatten från Solfontänen, magisk dryck.

### Solfontänen

Om spelarna lyckas rena [Skuggfontänen](https://docs.google.com/document/u/0/d/1pcnL5zcsdU0yIms68k_RPjezrQvXxb38D9zehynikas/edit) (så den återgår till att bli Solfontänen) så kan de tvätta sig och dricka fontänens vatten, för att bli botade från skuggpesten.

### Magisk dryck

Lärlingen Alaric kan skapa drycken, men bara om följande punkter uppfylls:

* Spelarna har hittat mästarens förlorade formler och gett dem till Alaric.
* Spelarna ledsagar Alaric till Apoteket Valeria i Allmogens kvarter.
